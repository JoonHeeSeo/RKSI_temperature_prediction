## /training

| Command                                      | Description                          |
| -------------------------------------------- | ------------------------------------ |
| uv run python -m training.train_all          | All                                  |
| uv run python -m training.train_linear       | Linear                               |
| uv run python -m training.train_lstm         | LSTM                                 |
| uv run python -m training.train_mlp          | 다층 퍼셉트론(MLP)                   |
| uv run python -m training.train_gru          | GRU (Gated Recurrent Unit)           |
| uv run python -m training.train_tcn          | Temporal Convolutional Network (TCN) |
| uv run python -m training.train_transformer  | Transformer 계열                     |
|                                              |                                      |
